Setup

Build the executable with make build from the source directory. Configure a provider in ~/.config/pipkin/.env or set the corresponding environment variables. For example, an OpenAI-compatible text provider uses the following settings.

PIPKIN_PROVIDER=openai
PIPKIN_BASE_URL=https://api.openai.com/v1
PIPKIN_MODEL=your-model-id
PIPKIN_API_KEY_ENV=OPENAI_API_KEY
LISTEN_URL=http://127.0.0.1:8787

Supply the named API key to the Pipkin process and run pipkin --web /path/to/project. Run pipkin /path/to/project for the terminal picker. Provider and agent profiles can be set in ~/.config/pipkin/config.json or in the file specified by PIPKIN_CONFIG.

Usage

For a text-only answer, open Free prompt or press f in the TUI. Use the history list to start or return to a conversation. In the TUI, press Enter to open, n for a new conversation, and d then Y to delete. In the composer, Enter adds a line, Ctrl+S sends, Ctrl+T opens the transcript, and Esc returns to history.

Press Enter or v on a highlighted text file in the TUI to preview it. Press q or Esc to return to the picker.

  1. Select the files and folders the provider should receive.
  2. Enter the change you want. Use Agentic mode for a draft followed by one or more review passes.
  3. Review the changes and approve individual files before copying them into the workspace.

Pipkin uses your root AGENTS.md when customised and shows the built-in default under Instructions when the workspace has no custom project guidance. Open Instructions to edit it, create or enable skills under .agents/skills/<name>/SKILL.md, or add a workspace prompt and explicit Markdown paths. The terminal picker opens the instruction editor with I. The CLI accepts repeated --instructions path.md flags.

pipkin --workflow --agentic --files-from files.json \
  --prompt-file task.txt --instructions AGENTS.md .

files.json is a JSON array of project-relative file or folder paths. The task goes in task.txt. System instructions guide the work alongside Pipkin's output and tool constraints.

Open Project or press J to select a profile or initialise a repository. Pipkin writes the choice to .pipkin-project.json and applies the profile guidance to prompts.

Open Workbook to inspect a CSV or XLSX file or change cells in a separate workbook copy. In the TUI, highlight a spreadsheet and press W. In a CSV, use the arrow keys to move, Enter to edit, and s to save a new copy. XLSX support requires openpyxl>=3.1 in Python. Set PIPKIN_XLSX_PYTHON to select that interpreter.

pipkin --workbook budget.xlsx --workbook-edits edits.json --workbook-output budget-reviewed.xlsx .

MkDocs export

Select your source files and enter a documentation brief. Press D in the TUI or choose Export MkDocs ZIP in the web picker. Unzip the result, install its requirements.txt, and run mkdocs serve from the extracted folder.

HTTP API

The local web interface serves HTML. POST requests use URL-encoded form fields and the csrf token from the relevant page. Delivery and instruction mutations redirect with HTTP 303. Free prompts return replies directly when the client requests JSON. Use repeated form fields for file selections and per-delivery instruction files.

GET /
File picker and deliveries. Use hidden=1 to reveal eligible dotfiles or from=PROJECT/JOB-ID to reuse a task and selection.
GET /about and GET /help
Build and workspace metadata and this reference.
POST /mkdocs
Accepts prompt, repeated files, and optional provider_profile, system_prompt, repeated instruction_files, and show_hidden=1. Returns the MkDocs ZIP attachment.
GET /project and POST /project
Show or set the workspace profile. POST accepts profile and optional action=init.
GET /workbook and POST /workbook
Inspect file. To edit, supply output and a JSON edits array with sheet, cell, value, and optional kind=formula.
GET /prompt and POST /prompt
GET lists conversations or opens the transcript named by conversation. POST accepts prompt and optional conversation, provider_profile, system_prompt, and repeated instruction_files. Use action=delete with a conversation ID to delete it. With Accept: application/json, POST returns reply and conversation for a prompt, or deleted for deletion.
GET /instructions and POST /instructions
Read or save workspace guidance. POST accepts system_prompt and a newline-separated instruction_files field, and optional skip_project_instructions=1.
GET /instructions/edit and POST /instructions/edit
GET accepts path or a new skill name. POST accepts path and markdown, or path and action=toggle to enable or disable a skill.
POST /submit
Accepts prompt, repeated files, and optional provider_profile, agentic=1, show_hidden=1, system_prompt, and repeated instruction_files. Starts a delivery and redirects to its review.
GET /review
Accepts job=PROJECT/JOB-ID and optional mode=submitted or mode=current.
POST /decision
Accepts job, action, path for single-file decisions, and optional mode. Actions are approve, reject, reset, approve-all, and reject-all.
POST /copy
Accepts job and confirm=COPY. Pending decisions or workspace conflicts return HTTP 409.
GET /git
Read-only repository history or patch. Accepts optional path, local=1, diff (upstream, working, or commit), and a full commit object ID for a commit patch.

MCP

Configure your MCP client to launch the Pipkin executable over stdio with the argument --mcp. Configure the provider in the server process environment or its Pipkin config. Use absolute paths for root and job, and project-relative paths for selected files and instructions.

pipkin_mkdocs(root, paths, prompt)
Returns the ZIP path and any omitted files. Optional arguments are provider_profile, system_prompt, and instruction_files.
pipkin_project(root, action, profile?)
Actions are show, set, and init.
pipkin_workbook(root, file, output?, edits?)
Preview a CSV or XLSX spreadsheet or apply edits to a new copy and return the cell changes.
pipkin_prompt(root, prompt)
Returns reply and conversation. Optional arguments are conversation, provider_profile, system_prompt, and the array instruction_files.
pipkin_conversations(root, action)
Actions are list, read, and delete. Read and delete require the conversation ID.
pipkin_instructions(root, action)
Actions are list, read, save, and toggle. Include file except for list. Include markdown for save.
pipkin_pack(root, paths)
Creates a ZIP and returns its path and file count.
pipkin_submit(root, paths, prompt)
Runs the delivery and returns job and result. Optional arguments are agentic, system_prompt, and the array instruction_files.
pipkin_jobs(root)
Lists saved jobs.
pipkin_review(job)
Returns the saved job and reviewable file changes.
pipkin_apply(job, file)
Applies one reviewed file after explicit approval. The server must be started with PIPKIN_MCP_ALLOW_APPLY=1.
