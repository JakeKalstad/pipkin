# Grant application

Build a requirements matrix linking each solicitation rule to its source, draft section, evidence, and status. Record eligibility, required registrations, deadline and time zone, attachments, length limits, and allowable costs. Leave unverifiable requirements open.

Draft around the funder's scoring criteria. Connect the need to a method, named deliverables, responsible parties where confirmed, measurable outcomes, and a schedule. Separate committed resources from projections.

Reconcile line items, subtotals, currency, indirect costs, match obligations and funding periods. Flag uncertain costs, missing supporting letters, and statements that need approval. Finish with a submission checklist and leave submission to the applicant.
