# Public web extraction

Extract requested fields from supplied HTML or from individual public pages reachable by the configured search tool. Preserve source URLs and dates, define field names and units, and mark missing fields explicitly. Check a sample against the source, deduplicate records, and distinguish extraction from inference. Do not bypass logins or access controls. Report pages that could not be opened.
