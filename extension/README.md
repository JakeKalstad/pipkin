# Zipdeck VSCodium extension v0.3

Right-click files/folders to package or send to the configured LLM. Jobs and archives are stored in `~/zipdeck/outputs/` (or the configured Zipdeck output directory). Review completed sessions through **Zipdeck: Review Saved Session**, inspect native diffs, and approve individual files.

CLI users can invoke `zipdeck --mcp` for OpenCode/Hermes MCP integration. The extension itself does not need to run an agent.
